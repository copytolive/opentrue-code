# OpenTrue Project Rule

- Prefer the smallest coherent change that solves the task.
- Read `AGENTS.md` before editing.
- Search for existing implementations before creating new modules.
- Run the relevant lint, typecheck, tests, and build after writes.
- Never print, copy, commit, or upload credentials, `.env` files, private keys, wallets, database dumps, or user data.
- Treat push, merge, production deploy, destructive restore, DNS/firewall/secret/billing changes as approval-gated actions.
- A task is not complete merely because code was written; report the exact checks and receipts that actually ran.
